# ผลตรวจโมเดลเวอร์ชัน 2

เวอร์ชันนี้ปรับจากโมเดลเดิมให้ใกล้ภาพอ้างอิงขึ้น โดยเก็บไฟล์เดิมแยกไว้ เปิด `compare.html` เพื่อเทียบภาพและซ้อน ref บนภาพโมเดลได้

| ส่วน | การเปลี่ยนแปลง |
|---|---|
| สัดส่วน | ขยายความกว้างใบหน้าและไหล่ ปรับความลึกของศีรษะ เงยหน้า และปรับตำแหน่งหูฟังให้สัมพันธ์กับภาพ |
| ใบหน้า | รวมแก้ม กราม และปากเป็นผิวต่อเนื่อง ยืดปากกับสันจมูก ปรับจมูกสามเหลี่ยมมน เพิ่มเปลือกตาและขน geometry |
| หนาม | เปลี่ยนกรวยเดิมเป็นช่อหนามโค้งซ้อนหลายชั้น มีแนวเส้นและสีปลายอ่อน |
| อุปกรณ์ | แว่นกรอบเหลี่ยมพร้อมเลนส์สีฟ้าและไฟ HUD หมวกมีพื้นผิวถัก หูฟังมีชั้นฟองน้ำ โลหะ และวงไฟ |
| เสื้อผ้า | สร้างแจ็กเก็ตจากผิวต่อเนื่อง เพิ่มปก ฮู้ด ผิวผ้า แผงอก ซิป เกราะแขน และหัวเข็มขัดไหล่ |
| สี | ใช้กลุ่มสีครีม–น้ำตาล เทอร์ควอยซ์ กรมท่า โลหะเข้ม และ cyan พร้อมแยก base color กับ normal map |

## ผลตรวจไฟล์

- GLB เว็บ: **16.82 MB**, **229,544 สามเหลี่ยม**, 19 mesh objects และ 18 วัสดุ
- ฝัง texture ทั้งหมดใน GLB ไม่มีไฟล์ texture ภายนอกที่ต้องโหลดเพิ่ม
- ตรวจ GLB header, buffers, accessor bounds, index, ค่า finite และความยาว normal ผ่าน ไม่พบสามเหลี่ยมที่มี index ซ้ำ
- นำ GLB กลับเข้า Blender สำเร็จ ขอบเขตพิกัด vertex ทั้งโมเดลตรงกับต้นฉบับ
- ภาพ GLB ที่นำเข้ากลับต่างจากภาพต้นฉบับ Blender โดยเฉลี่ยประมาณ **0.0086 บนสเกล RGB 0–1** ภายใต้กล้องและแสงเดียวกัน ค่านี้เป็นการตรวจการส่งออก ไม่ใช่คะแนนความเหมือน ref
- จุดอ้างอิงที่ระบุด้วยมือ 6 จุดคลาดจาก ref ประมาณ **0.7–2.7% ของความกว้างภาพ** เป็นเพียงตำแหน่งตา จมูก หูด้านใกล้ และหูฟัง ไม่ครอบคลุมรูปทรงหรือ silhouette ทั้งหมด

## ข้อจำกัดที่ยังเห็นได้

โมเดลยังมีลักษณะ stylized มากกว่าภาพต้นฉบับ ขนละเอียดและการไล่ขนรอบดวงตายังไม่หนาแน่นเท่า ref รูปหน้ากับเปลือกตา หมวก แผงเสื้อ รอยยับ และช่อหนามยังมีรูปทรงต่างกัน สีขึ้นอยู่กับแสงและ tone mapping จึงยังไม่ใช่การยืนยันความตรงของสีเชิงการวัด ส่วนด้านหลังออกแบบต่อจากข้อมูลด้านที่มองเห็น และไม่มีข้อมูลขนาดจริงจากภาพ

ยังไม่มี rig/animation ไม่ได้รัน Khronos validator หรือ glTF Transform เนื่องจากติดข้อจำกัดการเข้าถึง dependency และยังไม่ได้ทดสอบ WebGL/ประสิทธิภาพในเบราว์เซอร์ เพราะระบบอนุมัติปฏิเสธการเปิดเบราว์เซอร์อัตโนมัติ การตรวจนำเข้ากลับทำด้วย Blender/Cycles

ไฟล์ `.blend` มีรูปอ้างอิงและ texture แบบ packed อยู่แล้ว รูปอ้างอิงซ่อนอยู่ใน collection `Reference_Not_Exported` และไม่รวมใน GLB
